# Tool logos

The marks of the tools shown as tiles on the Poster. Each file is the tool's own mark as a
single-colour SVG; the only change made here is the `fill` colour on the `<svg>` element.
The home page serves the copies in `static/home/logos/`; the list of tools is in
`content/_index.md` (`[[extra.tools]]`).

The marks are trademarks of their owners and are shown only to name the tools Edouard uses.

official SVG here and in `static/home/logos/`, add a row above, and add the tool to the list in
`content/_index.md`.
