# Orange brand stickers (Edouard the Ginger, 12 Nov 2026)

90 transparent PNGs drawn from scratch in the vibe of the Pinterest references in
`../../References/Orange_Brand_Vibe/`: grainy orange crayon doodles, thin pencil arrows with a loop, crumpled
orange paper. Colours: crayon #EC6224, bright #FF700A, pencil #F3962E, brand box #C63B00, cream #FFF4E6.
Hand lettering: `../../Fonts/Hand_Lettering/PermanentMarker-Regular.ttf` (Apache 2.0).

Previews: `_contact_sheet_light.jpg`, `_contact_sheet_dark.jpg`.
Regenerate or add more: `uv run --with numpy --with pillow python make_orange_brand.py`.
