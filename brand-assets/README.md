# Brand assets

Source files for the site's look. Templates should copy or process what they need from here; do not edit these.

- `portrait/portrait.jpg`: Edouard's portrait (the photo behind their TikTok and Instagram profile picture). `profile_crop_reference.jpg` shows how the profile picture crops it.
- `fonts/`: Montserrat Bold and Black (SIL Open Font License, see the licence file). Self-host these; do not load fonts from a third party.
- `stickers/`: Edouard's orange crayon stickers (arrows, badges, pills, tape strip, crumpled paper, cursor). Transparent PNGs, large: resize at build time.

Colours: background `#FAF8F5`, orange `#C63B00`, yellow `#FFB926`, charcoal `#191919`, muted `#665F58`, border `#D6CDC3`, pale fill `#F3F0EB`.
